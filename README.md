# hor-webshop-filter

A responsive, client-side webshop catalog demo built with React, TypeScript, and Vite. Search by product name, narrow by category, or set a maximum price; active filters combine.

## Development

```sh
npm ci
npm run dev
```

## Quality checks

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

The sample catalog is static. Product requirements and test mappings are in [PRD.md](PRD.md); the project structure is described in [ARCHITECTURE.md](ARCHITECTURE.md).
